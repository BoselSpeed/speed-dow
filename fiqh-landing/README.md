# تطبيق الفقه - Fiqh App Landing Page

صفحة هبوط ثابتة (Static Landing Page) لتطبيق أندرويد إسلامي "تطبيق الفقه".

## 🚀 النشر على Surge.sh

```bash
# تثبيت Surge إذا لم يكن مثبتًا
npm install -g surge

# النشر من المجلد
cd fiqh-landing
surge ./ speed-dow.surge.sh
```

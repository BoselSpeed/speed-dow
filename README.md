# نادي متعدد المجالات - المدرسة العليا للأساتذة ملحقة سوڨر تيارت

موقع إلكتروني ثابت (Static Website) لنادي متعدد المجالات في المدرسة العليا للأساتذة ملحقة سوڨر تيارت، ولاية تيارت، الجزائر.

## نظام التصميم

يتبع الموقع نظام تصميم احترافي مبني على المتغيرات (CSS Custom Properties) مع:

- الألوان: أزرق داكن أساسي `#0E3A53`, أزرق ثانوي `#146C9C`, ذهبي مميز `#E8A33D`
- الخطوط: Amiri (العناوين), Cairo (النصوص)
- تخطيط أولوية الهاتف (Mobile-First)، متجاوب مع جميع الشاشات
- نظام مسافات مبني على 8 بكسل

## هيكل الملفات

```
index.html          # الصفحة الرئيسية الثابتة
form.html           # نموذج الانضمام والتسجيل (مثل Google Form)
admin/index.html    # لوحة التحكم الإدارية (الرابط /admin)
css/style.css       # أنماط الموقع
js/config.js        # إعدادات الروابط البديلة الموحدة
js/main.js          # سكربتات بسيطة (القائمة، النموذج، التخزين)
assets/images/      # مجلد الصور
```

## الصفحات

1. **الصفحة الرئيسية** (`index.html`) -hero, عن النادي, التخصصات والمجالات, الأنشطة, الانضمام, التواصل
2. **نموذج التسجيل** (`form.html`) - نموذج متعدد الخطوات للبيانات الشخصية والتخصص والمعلومات الإضافية
3. **لوحة التحكم الإدارية** (`admin/index.html`) - عرض وإدارة التسجيلات، إحصائيات، تصدير البيانات (محمي بكلمة مرور)

## الروابط البديلة الأربعة

الموقع يحتوي على أربعة روابط بديلة موحدة يمكن تعديلها من ملف واحد:

**ملف التكوين:** `js/config.js`

```javascript
const PLACEHOLDER_LINKS = {
  PLACEHOLDER_LINK_1: '#',
  PLACEHOLDER_LINK_2: '#',
  PLACEHOLDER_LINK_3: '#',
  PLACEHOLDER_LINK_4: '#'
};
```

تظهر هذه الروابط في تذييل الصفحة تحت قسم "روابط سريعة". لتعديلها، عدل valores في `js/config.js` فقط.

## المواصفات التقنية

- موقع ثابت (Static) – لا Backend، لا قاعدة بيانات، لا تسجيل دخول للمستخدمين
- HTML وCSS وJavaScript بسيط فقط
- التخزين المحلي (localStorage) لنماذج التسجيل
- متوافق مع إمكانية الوصول (WCAG AA)
- دعم `prefers-reduced-motion`
- روابط تخطي إلى المحتوى (Skip Link)
- تحميل سريع، أكواد نظيفة ومنظمة

## المواصفات المتجاوبة

تم اختبار الموقع على أحجام الشاشات التالية:
- 320px (هاتف محمول)
- 375px (هاتف محمول)
- 768px (حاسوب لوحي)
- 1024px (لابتوب)
- 1440px (حاسوب مكتبي)

## ملاحظات الصور

الموقع يستخدم صوراً في `assets/images/` يجب استبدالها بصور فعلية للنادي قبل النشر.

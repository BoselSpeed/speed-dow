# Club Aris – Static Website

موقع إلكتروني ثابت (Static Website) لنادي آريس (ARIS) – مساحة آمنة وشاملة لمجتمع 2SLGBTQIA+ في مونكتون، نيو برونزويك، كندا.

##設計 approach

يتبع الموقع نظام تصميم **Premium Minimalist Designer** الموثق في `docs/design-systems/club-aris-three-designers.md`، مع الحفاظ على الهوية البصرية الأصلية لنادي آريس:

- الألوان: خلفية بيضاء، نغمات كاربون `#1A1A1A`، ذهب دافئ `#FFFD47` (من الهوية الأصلية)
- الخطوط: Modak (الشعار والعناوين الكبيرة)، Playfair Display (العناوين)، Arimo (النصوص)
- تخطيط أولوية الهاتف (Mobile-First)، متجاوب مع جميع الشاشات

## هيكل الملفات

```
index.html          # الصفحة الرئيسية الثابتة
css/style.css       # أنماط الموقع (نظام تصميم Premium Minimalist)
js/main.js          # سكربتات بسيطة (القائمة الجانبية، النموذج، التمرير)
assets/images/      # مجلد الصور (يتم استبداله بصور النادي الفعلية)
docs/               # وثائق أنظمة التصميم الثلاثة للمصممين
```

## الأقسام

1. رأس الصفحة والتنقل (Header & Navigation)
2. البطولة الرئيسية (Hero Section)
3. عن النادي (About)
4. الصور والمنشورات (Gallery)
5. الخدمات والأنشطة (Services)
6. المميزات (Features)
7. التواصل (Contact)
8. إنستغرام والشبكات الاجتماعية (Instagram)
9. تذييل الصفحة (Footer)

## المواصفات التقنية

- موقع ثابت (Static) – لا Backend، لا قاعدة بيانات، لا تسجيل دخول
- HTML وCSS وJavaScript بسيط فقط
- متوافق مع إمكانية الوصول (WCAG AA)
- دعم `prefers-reduced-motion`
- روابط تخطي إلى المحتوى (Skip Link)
- تحميل سريع، أكواد نظيفة ومنظمة

## ملاحظات الصور

الموقع يستخدم صوراً افتراضية (SVG Placeholders) داخل الكود. يجب استبدالها بصور عالية الدقة من حساب نادي آريس على إنستغرام قبل النشر الفعلي.

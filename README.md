# نادي متعدد المجالات - المدرسة العليا للأساتذة ملحقة سوڨر تيارت

موقع إلكتروني ثابت (Static Website) لنادي متعدد المجالات في المدرسة العليا للأساتذة ملحقة سوڨر تيارت، ولاية تيارت، الجزائر.

## نظام التصميم

يتبع الموقع نظام تصميم احترافي مبني على الألوان البني والأبيض (مستوحى من الطبيعة والرفاهية):

- **اللون الأساسي (Primary Brown):** #5D4037
- **اللون الأساسي الغامق:** #3E2723
- **اللون الثانوي:** #8D6E63
- **لون التمييز (Accent):** #B8860B (ذهبي)
- **الخلفية:** #FFFFFF (أبيض)
- **سطح النظام:** #EFEBE9
- **النص:** #212121
- **النص المبهم:** #6D4C41
- **الحدود:** #D7CCC8

**الخطوط:**
- Amiri (العناوين)
- Cairo (النصوص)

## هيكل الملفات

```
index.html          # الصفحة الرئيسية الثابتة
form.html           # نموذج الانضمام والتسجيل (مثل Google Form)
admin/index.html    # لوحة التحكم الإدارية (الرابط /admin)
css/style.css       # أنماط الموقع (بني وأبيض مع تأثيرات CSS motion)
js/config.js        # إعدادات الروابط البديلة الموحدة
js/main.js          # سكربتات بسيطة (القائمة، النموذج، التخزين)
assets/images/      # مجلد الصور
```

## الصفحات

1. **الصفحة الرئيسية** (`index.html`) - Hero, عن النادي, التخصصات والمجالات, الأنشطة, الانضمام, التواصل, إنستغرام
2. **نموذج التسجيل** (`form.html`) - نموذج متعدد الخطوات للبيانات الشخصية, المجموعة والتخصص, الفريق والاهتمامات, الرسالة والتأكيد
3. **لوحة التحكم الإدارية** (`admin/index.html`) - عرض وإدارة التسجيلات، إحصائيات، تصدير البيانات (محمي بكلمة مرور: admin123)

## الروابط البديلة الأربعة

الموقع يحتوي على أربعة روابط بديلة موحدة يمكن تعديلها من ملف واحد:

**ملف التكوين:** `js/config.js`

```javascript
const PLACEHOLDER_LINKS = {
  PLACEHOLDER_LINK_1: '#',
  PLACEHOLDER_LINK_2: '#',
  PLACEHOLDER_LINK_3: '#',
  PLACEHOLDER_LINK_4: '#'
};
```

تظهر هذه الروابط في تذييل الصفحة تحت قسم "روابط سريعة". لتعديلها، عدل القيم في `js/config.js` فقط.

## المواصفات التقنية

- موقع ثابت (Static) – لا Backend، لا قاعدة بيانات، لا تسجيل دخول للمستخدمين
- HTML وCSS وJavaScript بسيط فقط
- التخزين المحلي (localStorage) لنماذج التسجيل
- متوافق مع إمكانية الوصول (WCAG AA)
- دعم `prefers-reduced-motion`
- روابط تخطي إلى المحتوى (Skip Link)
- تحميل سريع، أكواد نظيفة ومنظمة

## المواصفات المتجاوبة

- 320px (هاتف محمول)
- 375px (هاتف محمول)
